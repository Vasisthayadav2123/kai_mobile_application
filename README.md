# K.A.I. Mobile App (Kinetic AI Interface Client) 📱

This is the React Native Expo mobile client for K.A.I., offering a high-performance portal to interact with your host computer.

---

## 🚀 Key Client Controls & Features

### 1. WebRTC Screen Stream
* **Interactive Screen**: Renders the remote desktop screen inside a WebRTC HTML5 video player wrapped in a native `WebView`.
* **Gesture Mapping**: Allows fully functional mouse controls:
  - Single Tap: Click
  - Double Tap: Double click
  - Drag: Drag windows and select elements
  - Two-Finger Drag: Vertical scrollwheel manipulation

### 2. Stream Orientation Toggle (New Feature)
* **Portrait (Default)**: Normal vertical layout showing the full desktop stream letterboxed.
* **Landscape Mode**: Rotates the remote desktop stream by `90 degrees` clockwise to fill the screen length. This allows the user to hold the phone sideways to view the desktop details in a clean, larger landscape resolution. Touch positions are automatically translated counter-clockwise client-side before sending.

### 3. Remote Inputs (New Features)
* **Windows Key Control**: A Windows Start Menu button in the top menu bar that triggers the Start Menu on the host computer.
* **Typing Keyboard**: A keyboard button that focuses a hidden input. This raises the native soft keyboard, letting you type and press backspace directly onto the remote desktop session.

### 4. Voice Assistant Tab
* Sends real-time voice recordings to the backend to command K.A.I. (e.g. "open browser", "raise volume", or ask general queries).
* Plays back high-fidelity voice responses generated by the server.

## ⚙️ Get Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run the Expo application**:
   ```bash
   npx expo start
   ```
   Open the app via Expo Go on Android or iOS.
